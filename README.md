# digital-nomad-sweet-spot
Analysis of affordability, safety and internet speed across 151 cities. 

I used data on 151 cities to look at how often these three things actually come together. Rather than choosing arbitrary cutoffs, I used the medians of the dataset as benchmarks. A city had to have:
- below-median monthly living costs
- above-median safety
- above-median internet speed
Only **17 of 151 cities (11.3%)** met all three conditions.

The analysis was completed in **R**, using `tidyverse`, `ggplot2`, and `ggrepel`.

The full analysis and visualization code is available in: `digital-nomad-sweet-spot.Rmd`
